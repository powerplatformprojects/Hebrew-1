# Hebrew Verb Builder

A mobile-first Hebrew conjugation practice app.

## Features
- Word picker and tense picker on the practice screen
- Animated Hebrew prefix/suffix construction
- Pronoun icons
- Hear it / Say it speech practice
- Success sound and large visual success feedback
- Next button cycles conjugations and advances to the next word after the last one
- About 50 Hebrew word/root entries, with a randomized session set each load
- Progress saved in the browser with localStorage

## Hosting
Upload the contents of this folder to GitHub Pages, Netlify, or Cloudflare Pages. Speech recognition works best from an HTTPS URL on Android Chrome/Edge.
